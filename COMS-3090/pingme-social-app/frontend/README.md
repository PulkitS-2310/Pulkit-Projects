# PingMe Frontend

Android frontend for the PingMe social media application.

## Main Files/Folders

- `app/src/main/java/` - Java source code
- `app/src/main/res/` - layouts, drawables, menus, navigation, and app resources
- `app/build.gradle` - Android app Gradle configuration
- `settings.gradle` - project settings

## Notes

Generated files such as `.gradle/`, `.idea/`, and `build/` were intentionally removed.
