# PingMe Backend

Spring Boot backend for the PingMe social media application.

## Main Files/Folders

- `src/main/java/` - backend controllers, models, repositories, and services
- `src/test/` - backend tests
- `pom.xml` - Maven dependencies and project configuration
- `src/main/resources/application-example.properties` - safe configuration template

## Security Note

Do not upload real database passwords or server credentials to GitHub. Create your own local `application.properties` file from the example when running the project.
